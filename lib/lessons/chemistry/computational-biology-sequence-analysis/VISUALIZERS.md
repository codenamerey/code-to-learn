## Overview

## Course Structure

- **Course**: Computational Biology: Sequence Analysis Fundamentals
- **Slug**: `computational-biology-sequence-analysis`
- **Lessons**: 4 lessons with visualizers

## Visualizer Configurations Added

### Lesson 1: DNA Sequencing - Sanger Method

**File**: `lesson-1/visualizer.ts`

**Template**: `table`

**Purpose**: Displays DNA fragments from Sanger sequencing in a tabular format

**Data Structure**: Array of `DNAFragment` objects

```javascript
{
  id: number,
  length: number,
  terminalBase: string ('A', 'C', 'G', 'T')
}
```

**Configuration**:

```json
{
  "template": "table",
  "dataMapping": {
    "properties": ["id", "length", "terminalBase"]
  },
  "style": {
    "colorScheme": "biology",
    "showLabels": true,
    "showValues": true
  }
}
```

**What Students See**: A table showing each DNA fragment's ID, length, and terminal base, making it easy to understand how Sanger sequencing works.

## How It Works

### 1. Course Generation

The course was generated by AI with `includeVisualizer: true` in the course.json:

```json
{
  "id": 1770699036589,
  "title": "Computational Biology: Sequence Analysis Fundamentals",
  "slug": "computational-biology-sequence-analysis",
  "includeVisualizer": true,
  "lessonCount": 4
}
```

### 2. Visualizer Files

Each lesson now has a `visualizer.ts` file that exports configuration:

```typescript
export const visualizerConfig = {
  template: "table", // or "graph", "array", "chart", "grid"
  dataMapping: {
    /* ... */
  },
  style: {
    /* ... */
  },
};
```

### 3. Runtime Loading

When a student loads a lesson:

1. The lesson API loads `visualizer.ts` (if it exists)
2. Passes the config to `TemplateRenderer`
3. Student's function output is fed to the template
4. Template renders the visualization automatically

### 4. Student Experience

When students run their code:

- The Output panel shows text results and test results
- The Visualizer panel shows the template-rendered visualization
- No custom code needed - all configuration-driven
